# tic-tac-toe-game

I created a web-based multiplayer Tic-Tac-Toe game using Node.js, JavaScript, Socket.IO, and MySQL. The Node.js server managed the game logic and communicated with players through Socket.IO. Players could log in, join games, take turns, and receive game updates in real time. MySQL was used to store player information, and the application was hosted on an AWS EC2 Ubuntu server.

Node.js、JavaScript、Socket.IO、MySQLを使って、Webベースのマルチプレイヤーの三目並べゲームを作りました。Node.jsのサーバーでゲームのルールやゲームの進行を管理し、Socket.IOを使ってプレイヤーとリアルタイムで通信しました。プレイヤーはログインしてゲームに参加し、順番にゲームをすることができます。MySQLはプレイヤーの情報を保存するために使い、AWS EC2のUbuntuサーバーでアプリケーションを動かしました。
